# WP T-Shirt Designer

Prosty plugin dodający shortcode `[tshirt_designer]`, który wyświetla kreator koszulki. Umożliwia przesuwanie elementów w obszarze 30x40 cm (300 DPI), dodawanie obrazu PNG (do 10 MB) oraz tekstu z wyborem czcionki. Cena nadruku obliczana jest na podstawie powierzchni zadruku (0,10 zł za cm²). Projekt zapisywany jest jako plik PNG oraz miniatura i może zostać powiązany z produktem WooCommerce.

Instalacja:
1. Skopiuj katalog `wp-tshirt-designer` do folderu `wp-content/plugins/`.
2. Aktywuj w panelu WordPressa.
3. Dodaj shortcode `[tshirt_designer]` na stronie produktu.
